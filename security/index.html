安全使用

下载和安装时，最值得多看一眼的是来源

不用把安全问题想得很复杂。大多数时候，先确认下载来源、再看权限，就能避开一大半麻烦。

安装前先确认你是从哪里拿到文件的

网络加速类客户端需要较高的网络权限，所以下载来源比普通网页更重要。优途当前官网是 youtujsq9.net，优先从官网进入对应平台的下载方式，可以减少装到修改版、旧版本或冒名安装包的概率。

“破解版”“绿色版”“内部版”都别当捷径

这类文件通常没有稳定的官方更新来源。即使能运行，也很难知道有没有被二次打包、插入额外组件，或者长期停留在已经过时的版本。

系统安全提示怎么判断

Windows SmartScreen、Android 安装外部应用提示、macOS 网络权限弹窗本身都不等于恶意软件。判断重点是：你是不是刚刚从可信入口主动下载、弹窗里的应用名称是否一致、请求的权限是否和功能有关。

已经安装了来源不明的客户端

先卸载，再运行系统自带的安全检查，然后从官网重新安装。重要账号如果曾在可疑环境里输入密码，顺手改掉密码并检查登录记录。Android 还可以复查“安装未知应用”、辅助功能、设备管理等高权限是否留给了陌生应用。

看起来一模一样的网站也可能不是同一个域名

页面设计可以复制，域名才是最值得确认的地方。遇到拼写很像、带额外前后缀、跳转很多次的网站，可以去假冒网站识别看具体判断方法。

账号安全也别忽略

不要在不明网页里重复使用重要账号密码，也不要把验证码发给陌生人。客户端出了问题，优先使用官网提供的客服渠道处理，而不是让陌生人远程控制电脑或手机。
