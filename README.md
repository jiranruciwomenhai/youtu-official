# 优途加速器使用指南

这是一个围绕优途加速器真实用户任务组织的静态内容站，重点解决：确认官网、按设备下载、第一次连接、节点选择、连接故障和下载安全。

## 访问地址

- 内容站：https://jiranruciwomenhai.github.io/youtu-official/
- 优途官网：https://youtujsq9.net/
- 另一官方网站：https://yuutto.com/
- 官方帮助：https://youtujsq9.net/course.html

## 内容结构

- 官网入口与真假判断
- Windows、Android、iPhone / iPad、Mac 下载说明
- 第一次使用、智能/定制模式、节点选择
- 已连接但没网、速度慢和分平台连接排查
- ChatGPT、YouTube、Netflix 等具体服务场景分流
- 不限流量、多设备、专属节点与隐私安全说明

## 内容维护原则

- 每个页面围绕一个主要搜索任务，不为了关键词变体重复建页。
- 不托管客户端安装包，不提供来源不明或修改版文件。
- 不编造实测速度、延迟、版本、价格、错误码或用户评价。
- 官网入口、客户端界面、第三方平台规则等时效信息发生变化时，优先更新对应主页面和 sitemap `lastmod`。
- 能用官方资料核实的操作信息直接写清；无法核实的精确字段不做确定性表述。

## GitHub Pages 部署

项目为纯静态 HTML，可直接托管在 GitHub Pages。将仓库的 Pages 发布源指向包含 `index.html` 的分支和目录即可。

如果更换仓库名或绑定自定义域名，请同步修改页面中的 canonical、Open Graph URL、sitemap.xml 和 robots.txt，确保所有规范 URL 保持一致。
