# 优途加速器使用指南

这是一个用于整理优途加速器官网入口、客户端下载方式、功能说明和常见使用问题的静态网站项目。

## 访问地址

- 内容站：https://jiranruciwomenhai.github.io/youtu-official/
- 优途官网：https://youtujsq9.net/

## 主要内容

- 优途加速器官网地址与下载入口
- Windows、Android、iPhone / iPad、Mac 下载说明
- 节点、不限流量、多设备、专属节点等功能介绍
- 连接异常、速度变慢、视频缓冲等使用问题
- 下载来源与账号安全提醒

## GitHub Pages 部署

项目为纯静态 HTML，可直接托管在 GitHub Pages。将仓库的 Pages 发布源指向包含 `index.html` 的分支和目录即可。

如果更换仓库名或绑定自定义域名，请同步修改页面中的 canonical、Open Graph URL、sitemap.xml 和 robots.txt，确保所有规范 URL 保持一致。
