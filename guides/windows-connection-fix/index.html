Windows 排查

Windows 上优途连不上，先别急着卸载重装

Windows 的连接问题经常和网络适配器、系统代理、其他网络软件有关。先从影响最小的步骤开始，最后才考虑网络重置。

先看症状：是“点连接没反应”，还是“连上以后没网”

这两种情况不要混在一起查。按钮点下去就失败，更像客户端、权限或网络组件的问题；显示已连接但网页打不开，则先看系统代理、其他 VPN 和当前网络。

突然连接失败，先做三个低成本测试

先退出客户端重新打开，再换同地区另一条线路，最后把 Wi-Fi 临时换成手机热点。只要其中一步让连接恢复，就已经缩小了范围，不用急着动 Windows 的网络设置。

系统里有多个“接管网络”的软件吗

企业安全软件、虚拟机、代理工具、其他 VPN 都可能安装虚拟网卡或过滤驱动。最近刚装过这类软件，而问题也正好从那时开始，可以先暂停其中一个做对照。一次只改一项，判断会更准。

Windows 更新后才出问题

把待完成的系统更新装完并重启。Microsoft 在网络故障排查里也建议检查更新和重启；网络驱动或系统组件变化后，一次完整重启比反复点连接更有意义。

什么时候才需要“网络重置”

网络重置会移除并重新安装网络适配器，并恢复相关设置。Microsoft 特别提醒，执行后 VPN 客户端、虚拟交换机等网络软件可能需要重新配置。所以它适合放在最后，而不是当成第一步。

如果只是某个网站打不开

先用无痕窗口或另一个浏览器测试。其他网站都正常时，更应该检查目标服务本身、浏览器扩展或账号状态，而不是直接重装 Windows 客户端。

Microsoft 参考：Windows 网络连接排查

如果软件还没装好，去 Windows 下载页；如果显示连接成功但所有网页都打不开，看 已连接但没网。
