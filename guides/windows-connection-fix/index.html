Windows 排查

Windows 上优途连不上，先分清是哪一种失败

“点连接就失败”和“显示已连接但没网”不要混在一起查；Windows 还要特别留意网络驱动和虚拟网卡。

症状优先检查
点击连接立即失败客户端状态、当前线路、其他 VPN/代理/企业安全软件
提示网卡/驱动安装或加载失败官方安装版、网络代理驱动、虚拟网卡
显示已连接但所有网页不通先做整网对照，再看局部/全局代理和过滤驱动
只有一个浏览器或网站失败浏览器代理、扩展、缓存或目标服务，不先重装客户端

情况 A：点击连接就失败

  1. 退出客户端并重新打开。
  2. 换同地区另一条线路。
  3. 把 Wi‑Fi 临时换成手机热点做对照。
  4. 检查最近是否安装了其他 VPN、代理、虚拟机或企业安全软件。

情况 B：提示网卡安装或加载失败

官方 Windows 常见问题明确把这类提示与网络代理驱动联系起来，并建议重新从官网下载 Windows 安装版。官方资料也说明客户端会在软件驱动和虚拟网卡之间涉及不同的网络代理方式；具体勾选项以当前客户端为准，不照搬旧截图。

情况 C：显示已连接，但所有网页都打不开

先去 已连接但没网做“不开优途/开优途”的对照。Windows 上还要看系统代理、其他 VPN/过滤驱动以及当前是局部代理还是全局代理。

什么时候才考虑网络重置或重装

网络重置会影响已有网络适配器和其他网络软件配置，应该放在排查末尾。只有客户端安装损坏、官方明确提示驱动安装失败或重装条件成立时，才回到 Windows 下载页重新获取当前安装版。

排查原则：一次只改一项。驱动、节点、Wi‑Fi、代理和浏览器同时变化，恢复以后也很难知道真正原因。
