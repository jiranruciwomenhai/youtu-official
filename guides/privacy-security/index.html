隐私与安全

无日志、加密和 IP 保护不是同一件事

优途采用无日志记录、私有协议和加密连接；理解这三项能力各自解决什么，比把它们统称为“匿名”更有用。

三个概念分别解决什么

概念主要解决的问题不代表什么
加密连接 / 私有协议保护网络传输过程，降低中途直接读取数据的风险不自动隐藏你登录了哪个账号
节点出口 IP目标网站看到的是连接后的出口地址，而不是直接使用原网络出口不消除 Cookie、设备信息或账号记录
无日志记录产品采用无日志记录策略，不保存用户的上网活动日志不等于互联网其他服务都没有自己的记录

登录账号以后，网站仍然可能知道“你是谁”

VPN/加速连接不会自动删除浏览器 Cookie、设备信息和第三方网站自己的登录记录。网络层隐私和账号层隐私需要分开管理。

公共 Wi‑Fi 下仍要保护账号

重要账号继续使用强密码和双重验证，不在陌生网页输入验证码，也不要因为已经连接网络工具就忽略钓鱼页面。

团队独享 IP 和无日志是两个维度

独享 IP 解决的是出口一致性；无日志解决的是服务端活动记录策略。团队需要固定出口时可看 专属节点与独享 IP。
