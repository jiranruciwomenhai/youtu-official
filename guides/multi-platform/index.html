多平台

优途支持哪些设备？

Windows、Android、iPhone / iPad、Mac 都能覆盖。真正需要注意的是各系统的安装方式和权限并不一样。

电脑和手机都可以用

你确认的产品信息包括 Windows、Android、iOS 和 macOS 全平台支持，并支持超过 100 个设备同时在线。个人多设备、家庭设备和团队场景都可以放在同一套使用逻辑里管理。

Windows：重点看安装来源和系统网络组件

Windows 通常是下载安装程序后安装。SmartScreen、旧版本进程、其他 VPN 或网络工具都可能影响安装和连接。需要下载看 Windows 下载说明。

Android：APK 来源和临时权限更重要

Android 常见的是 APK 安装。浏览器可能需要临时“安装未知应用”权限，装完以后可以收回。不要为了方便长期开放，也不要把群文件里的 APK 当成官方最新版。

iPhone / iPad：先看 App Store 当前入口

苹果移动端更容易受商店地区和展示方式影响。优先从官网进入当前 Apple 下载教程，按商店实际显示的名称和入口操作，不要机械照搬旧截图。

Mac：还要留意网络扩展权限

macOS 的网络类应用可能请求系统网络权限。第一次安装或系统大版本更新后，如果出现连接异常，可以检查系统权限和其他 VPN 工具是否冲突。

100+设备同时在线，别忽略本地网络瓶颈

账号能支持大量设备，不代表所有设备同时跑高码率视频时，本地路由器、Wi‑Fi 和宽带也一定扛得住。团队使用时，设备数、出口带宽和是否需要独享 IP 是三个不同问题。

如果你真正关心的是大规模团队接入，可以继续看 100+设备怎么用 和 专属节点与独享 IP。
