第一次使用

第一次用优途加速器，按这个顺序来

目标不是一次学会所有功能，而是先完成一次可判断、可复现的正常连接。

1. 先进入客户端，不要一开始就改很多设置

官方常见问题说明，首次下载使用时可以进入游客模式体验；如果你已经登录自己的账号，也可以从当前客户端的登录入口切回游客登录。具体入口位置可能随版本调整，以当前界面为准。

2. 先弄清“智能模式”和“定制模式”

模式你能控制什么适合第一次使用吗
智能模式选择地区/国家，由客户端自动筛选该地区节点适合先把连接跑通
定制模式查看线路并手动选择具体节点适合需要比较节点或固定选择时

这两个概念和“智能加速/全局加速”不是同一层。官方 FAQ 还说明：智能加速属于局部代理，关闭后为全局代理。第一次测试时，不要同时切模式、换地区、换网络，否则出了问题很难知道原因。

3. 第一次连接怎么做

  1. 先用默认或智能模式，选择用途明确、距离相对合理的地区。
  2. 点击连接，等待连接状态变化。
  3. 官方 FAQ 提到：连接按钮旁出现连接时间，或手机顶部出现 VPN/钥匙图标，可作为“系统连接已建立”的第一层信号。
  4. 再打开一个普通网页和你真正要用的服务。系统显示已连接但网页打不开时，说明还需要继续排查。

一次正常连接至少满足三层：

① 客户端/系统显示连接已经建立；② 普通网页能打开；③ 你真正要用的服务也能正常加载。只满足第一层时，不要把问题误判成“已经完全正常”。

如果第一层成立、第二层失败，去 已连接但没网；前两层正常、只有某个服务失败，去 服务场景分流。

测试结果说明下一步
普通网页和目标服务都正常第一次连接已经跑通保持当前设置，不必继续调
系统显示已连接，但普通网页不通属于网络路径问题进入“已连接但没网”
普通网页正常，只有目标服务失败更像服务、账号、地区或浏览器问题进入服务场景分流

4. 第一次选节点，不追求“最远”或“最热门”

普通浏览先选符合目标地区、路径相对简单的线路。需要某个国家/地区的服务时，再把地区作为约束。想手动比较具体节点时再切定制模式。

5. 第一次出问题，只改一个变量

先断开并重连；仍不正常时，在同地区换一个节点；再不正常才换 Wi‑Fi/手机热点做对照。不要同时改地区、模式、DNS、浏览器和系统网络设置。
