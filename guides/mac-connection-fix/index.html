Mac 排查

Mac 上优途连接异常，先把网络变量一个个排除

macOS 的问题不一定出在客户端本身。公司网络、其他 VPN、网络过滤软件和系统更新，都可能改变实际连接结果。

症状优先检查
不开优途也不稳定Wi‑Fi/有线网络，本页后续节点操作先停
家里能连，公司/学校网络不行受管网络策略，用手机热点做对照
升级 macOS 后开始异常客户端当前版本、网络扩展/权限重新加载、重启
多个 VPN/过滤工具并存一次停用一个做对照，避免同时接管流量

先测试不连接优途时的网络

断开后打开几个网站。如果普通网络就不稳定，先处理 Wi-Fi 或有线网络；这一步能避免把本地断网误认为节点问题。

换同地区线路，别一次改太多设置

当前节点突然不稳定时，优先换同地区节点。连接恢复就先正常使用，不需要为了“彻底解决”去改 DNS、代理和系统权限。

检查其他 VPN、代理和过滤工具

Mac 上的企业安全软件、广告过滤、代理工具和其他 VPN 都可能接管网络流量。如果同时开着多个工具，先关闭一个再测，比较容易找到冲突。

刚升级 macOS 后出现异常

先确认客户端是当前版本，再重启 Mac。系统升级后网络扩展和权限可能重新加载，完整重启通常比连续点连接更有效。

公司或学校网络里连不上

有些受管网络会限制特定类型的连接。可以换手机热点测试。如果热点正常，说明设备和客户端大概率没坏，问题更可能和当前网络策略有关。
