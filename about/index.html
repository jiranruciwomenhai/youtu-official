关于本站

这个站点只做三件事：告诉用户正确的官方地址，说明各平台应从哪里开始下载，以及帮助用户识别来源不明的页面和客户端。

为什么使用 GitHub Pages？

GitHub Pages 提供一个公开、可访问、内容透明的静态页面，适合作为品牌地址核验和说明入口。本站不会把它包装成第二套下载系统。

本站不会做什么

  • 不托管优途加速器客户端安装包。
  • 不提供破解版、修改版或第三方重新打包版本。
  • 不使用隐藏文字、伪装页面或只给搜索引擎看的内容。
  • 不把未经核实的版本号、套餐、节点数量写成事实。
